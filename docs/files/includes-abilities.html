abilities.php

WordPress Abilities API integration

Registers one read-only ability, jpkcom-harden-trim/get-status: what every setting of this plugin does on this site and why. The answer comes from jpkcom_harden_trim_status(), the same function wp harden-trim status prints, so the two cannot disagree.

Its value is the cases nothing else shows at a glance: a switch that is on and does nothing (kill switch, a core constant that wins, a block theme), a value that does not come from the settings page (plugin constant, filter), and a constant that is ignored because its value is invalid.

The capability is manage_options: the answer describes how the site is hardened, which is configuration an administrator owns.

The labels, descriptions and messages stay English in every language, as in every JPKCom plugin's abilities: they are read by MCP clients and agents, and their wording is the feature.
