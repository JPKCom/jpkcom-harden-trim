admin-page.php

Settings page

Settings → Harden & Trim: one form for every setting, grouped by section (performance, head, privacy, security, roles), a presets form, and the save and preset handlers behind admin-post.php. All user-facing copy for the settings (labels, descriptions, choice names) lives in this file; import/export and the README reuse the labels.

jpkcom_harden_trim_redirect_with_notice()

admin-page.php : 304

Redirect back to the settings page with a message code, then stop.

jpkcom_harden_trim_redirect_with_notice(string $code[, array<string, array<int, string>> $lists = array() ]) : never

Key lists (changed, rejected, locked) go to the user-scoped transient; the URL only carries the code and the number of changed keys. Each list keeps at most jpkcom_harden_trim_notice_list_cap() entries; how many were cut is kept under more, so a hostile import with thousands of unknown keys cannot bloat the transient or the notice.

Parameters

A key of jpkcom_harden_trim_notice_messages().

$lists : array<string, array<int, string>> = array()

Key lists for the notice.

jpkcom_harden_trim_core_control_value()

admin-page.php : 614

What a field locked by a core constant shows: the core value, read the way core reads it.

jpkcom_harden_trim_core_control_value(string $key, mixed $value) : array{value: mixed, other: string|null}

The control of a core-locked field must show what is in effect, which is the core constant (core honours it and the feature code then does nothing), never the stored value or an ignored plugin constant. Core reads (7.1.3):

  • DISALLOW_FILE_EDIT: truthy disables the editors (capabilities.php:609).
  • WP_AI_SUPPORT: falsy disables AI (ai-client.php:23); the field is "Disable core AI features", so it is checked for a falsy value.
  • WP_POST_REVISIONS: true is unlimited, anything else is cast to int (revision.php:813-818); a negative number is unlimited as well, which is what "WordPress default" means for this field. 0 and the listed limits select their option.
  • AUTOSAVE_INTERVAL: seconds handed to the editor (script-loader.php:1962); 60 is core's own default (default-constants.php:381). A value no option names is returned as other, the text of an extra option the disabled select shows selected.
Parameters
$key : string

Setting key with a core constant.

$value : mixed

The core constant's value.

Tags
since
1.0.0
Return values
array{value: mixed, other: string|null} —

Control value; other is set when no option fits.
