import-export.php

Import and export

Export downloads the stored settings as JSON; import takes an uploaded file or pasted JSON, validates every value through the settings store and writes through it. The export carries no site address and no user data, so a file can move between sites as it is.

jpkcom_harden_trim_parse_import()

import-export.php : 170

Validate an import and merge it over the stored settings (writes nothing).

jpkcom_harden_trim_parse_import(string $raw) : array{settings: array, applied: list, rejected: list}|WP_Error

Every key in the file goes through the settings sanitiser on its own: a valid value is applied, an unknown key or an invalid value is rejected and the stored value stays, role slugs that do not exist on this site are dropped and reported as <key>:<slug>. Keys missing from the file keep their stored value.

Parameters
$raw : string

File or pasted content.

since
1.0.0
Return values

Complete settings to store, or an error with code too_large, invalid_json, wrong_plugin, unsupported_schema or no_settings.
