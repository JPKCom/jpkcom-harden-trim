settings-schema.php

Settings schema and presets

The single table of every setting this plugin knows: type, default, allowed values, section, whether the role exemption applies, the core constant that locks it, and the badges the settings page shows. Defaults and presets live here and nowhere else, so changing one of them is a one-line edit.
