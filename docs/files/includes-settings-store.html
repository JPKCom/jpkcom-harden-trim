settings-store.php

Settings store

Reads, validates and writes the single option this plugin owns, resolves constants and core locks, applies presets and decides the role exemption. Every other module goes through here, so validation cannot be bypassed by adding a caller.

jpkcom_harden_trim_save_settings(array<string, mixed> $input[, bool $keep_locked = true ]) : array{settings: array, rejected: list}

Keys missing from $input are stored with their default (a form sends every field; an unchecked role list sends nothing). Locked keys keep their stored value, whatever the input says, unless $keep_locked is false: an import stores what the file says for them too, and the constant still wins at runtime.

The roles a user holds for the role-based settings.

jpkcom_harden_trim_user_roles(WP_User $user) : array<int, string>
