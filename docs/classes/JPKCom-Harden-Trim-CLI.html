set()

cli.php : 202

Change one setting.

public set(array<int, string> $args, array<string, string> $assoc_args) : void

The value goes through the same validation as the settings page. A value that is not accepted, a setting locked by a constant, a role that does not exist on this site, and a setting the settings page does not offer with the active block theme are errors; nothing is written.

Values: switches take true/false (also 1/0, yes/no, on/off); choices take one of the listed words; post_revisions and autosave_interval take one of the listed numbers or default (the WordPress default); role lists take comma-separated role slugs, or an empty string for none.

OPTIONS

: Setting key, as listed by `wp harden-trim status`. : New value.

[--dry-run] : Validate and report, but write nothing.

EXAMPLES

$ wp harden-trim set emoji false
$ wp harden-trim set post_revisions 20
$ wp harden-trim set post_revisions default
$ wp harden-trim set exempt_roles administrator,editor

status()

cli.php : 97

Show what every setting does on this site, and why.

public status(array<int, string> $args, array<string, string> $assoc_args) : void

Lists the effective value, where it comes from (default, stored, constant, filter or a core constant), the constant that locks it, and whether the feature acts. A switch can be on and still do nothing: the reason column says why (kill_switch, core_constant, block_theme, plain_permalinks, unused, off). Role-scoped features additionally skip users holding an exempt role.

OPTIONS

[--fields=] : Limit the output to specific fields.

default: key,value,source,locked_by,acts,reason

[--format=] : Render output in a particular format.

default: table options:

  • table
  • csv
  • json
  • yaml

AVAILABLE FIELDS

key, group, type, value, stored, default, source, locked_by, core_value, acts, reason, role_scoped

EXAMPLES

$ wp harden-trim status
$ wp harden-trim status --format=json
$ wp harden-trim status --fields=key,value,stored,default
